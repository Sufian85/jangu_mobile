# Cypress E2E Harness + Test-Account Seed — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an isolated Cypress harness under `e2e/` that drives the live Jangu storefront in a real browser, and use it to create + verify the shopper account `+256701588030`.

**Architecture:** One top-level `e2e/` Node project (Cypress only). One spec, `account-smoke.cy.js`, with three ordered `it`s under `testIsolation: false` so they share a session: register (idempotent) → logout/login → add-to-cart smoke. UI-driven with resilient selectors (`#id_*` Django form ids, existing storefront markup hooks). No change to any file under `backend/`. Runs locally only — GitHub Actions is billing-blocked, so no CI workflow.

**Tech Stack:** Node 24 / npm 11 (already on the machine), Cypress (current release), plain JS (no TypeScript, no bundler config).

**Spec:** `docs/superpowers/specs/2026-09-09-cypress-e2e-harness-design.md` — approved.

**Deviation from spec (intentional):** the spec names `cypress ^13`. This plan installs the **current** Cypress release instead and pins whatever version resolves. Reason: the dev machine runs Node 24.13, which Cypress 13 does not officially support; the spec's intent was "a recent Cypress", which the current release satisfies.

Every command assumes you start from `/Users/mac/projects/jango_mobileapp`. The `e2e/` commands are run from `/Users/mac/projects/jango_mobileapp/e2e`. The Django app under test is the deployed site — no local server needed.

- [ ] **Step 2: Create `e2e/cypress/e2e/account-smoke.cy.js`**

```js
const user = require("../fixtures/test-user.json");
const password = Cypress.env("testPassword") || "JanguTest2026!";

describe("Storefront account: seed + verify +256701588030", () => {
  before(() => {
    // Pay any cold start once, before the real steps.
    cy.request({
      url: "/api/schema/",
      timeout: 120000,
      retryOnStatusCodeFailure: true,
    })
      .its("status")
      .should("eq", 200);
  });

  it("registers +256701588030, or confirms it already exists", () => {
    cy.visit("/register/");
    cy.get("#id_phone").clear().type(user.phone);
    cy.get("#id_first_name").clear().type(user.firstName);
    cy.get("#id_last_name").clear().type(user.lastName);
    cy.get("#id_password1").clear().type(password, { log: false });
    cy.get("#id_password2").clear().type(password, { log: false });
    cy.get('button[type="submit"]').click();

    cy.location("pathname", { timeout: 30000 }).then((pathname) => {
      if (pathname !== "/register/") {
        // Redirected away -> account created and auto-logged-in.
        cy.get('form[action*="logout"]').should("exist");
        return;
      }
      // Still on /register/ -- the only acceptable reason is a duplicate phone.
      cy.get(".errorlist")
        .invoke("text")
        .then((text) => {
          expect(text, "register error text").to.match(/already exists/i);
          cy.log("account +256701588030 already present -- skipping creation");
        });
    });
  });

  it("logs in with the seeded credentials", () => {
    cy.ensureLoggedOut();
    cy.login(user.phone, password);
    cy.location("pathname").should("not.eq", "/login/");
    cy.get('form[action*="logout"]').should("exist");
    cy.get(".site-header .header-actions").should("contain.text", user.firstName);
  });

  it("completes a shopper smoke journey while logged in", () => {
    // testIsolation:false keeps the login from the previous test. Re-login only
    // if this spec is run in isolation (e.g. with --spec on this file alone and
    // Cypress starting mid-describe on a retry).
    cy.visit("/");
    cy.get("body").then(($body) => {
      if (!$body.find('form[action*="logout"]').length) {
        cy.login(user.phone, password);
      }
    });

    cy.visit("/");
    cy.get(".product-grid a.product-card")
      .filter(":not(:has(.oos))")
      .first()
      .click();
    cy.location("pathname").should("match", /^\/p\//);

    cy.get("body").then(($body) => {
      if ($body.find("select[data-variant-select]").length) {
        cy.get("select[data-variant-select] option[data-in-stock='1']")
          .first()
          .then(($opt) => {
            cy.get("select[data-variant-select]").select(String($opt.val()));
          });
      }
    });

    cy.get("button[data-add-btn]").click();

    cy.location("pathname").should("eq", "/cart/");
    cy.get("ul.messages").should("contain.text", "Added");
    cy.get("table.cart-table tbody tr").its("length").should("be.gte", 1);
  });
});
```
